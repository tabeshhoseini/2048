## 2048 game rules:

1. you can only undo 3 times per game(each time to 5 previous moves!)
2. you can play in 10x10 board if you lead at least one leaderboard.
3. you can play in optional size board if you lead all three leaderboards.
4. you can shuffle the board, only once in every game.

## Folder Structure

The workspace contains two folders by default, where:

- `src`: the folder to maintain sources
- `lib`: the folder to maintain dependencies
